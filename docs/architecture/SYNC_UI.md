# 页面与首次迁移接入（WK-04）

遵循 US-04、US-09～US-12 和设备杯子独立约束。本阶段代码与模拟服务浏览器流程已验证，真实 Auth/REST、真实多设备与生命周期尚待验收，因此 `VITE_CLOUD_SYNC_PREVIEW` 默认关闭。保持默认值时现有本机使用和账号昵称不受影响，不调用记录同步 RPC。

## 首次接入

验证开关开启且已登录后，「我的 → 设置云同步」打开底部确认弹层，展示目标用户 ID、记录数、饮水/嘘嘘总计和杯容量。用户可取消，或选择：

1. 合并本机记录：稳定 ID 去重；相同 ID 不同内容拒绝迁移，原本机与云端均不替换；云端已删除的 ID 不复活。沿用本机杯子；云端已有目标时沿用云端目标，否则导入本机目标。
2. 仅恢复云端：不上传原本机记录。本设备有杯子备份时恢复本设备杯子，否则按本机容量开始新杯，不复制其他设备杯子。

先完整读取并校验云端分页，准备期间可取消、60 秒整体超时；任何网络错误、账号变化或源记录变化都拒绝切换。最终在 Web Lock 下复核原本机版本，并以单个 IndexedDB 事务写入账号快照、服务端版本/游标和新增队列。源 localStorage 不删除。初始化失败或重复初始化不留下半份快照。没有 Web Locks 的浏览器保留本机模式，暂不提供迁移。

先前已确认过的账号以账号快照存在为标志，刷新或离线重开时恢复其本机快照。设备本地保存最后选择的视图；即使过期凭据的 SDK 刷新仍在等待网络，也能先读取、导出和修改该本机快照。这个视图标记不是认证凭据，不允许据此发出 RPC；身份未恢复时只保留原账号队列并提示先导出。收到不同的有效 Auth 用户后立即隔离旧会话；新账号不会自动拿到旧账号快照或队列，没有其快照时回到独立本机模式并重新确认范围。正式账号登录/登出及过期后迁移入口仍留在 WK-05/06。

## 保存、通知与同步

- 页面所有写入均等待本机保存成功，再更新水位、累计和成功提示。立即用 ref 阻止重复提交；保存期间禁用主要写入和主动刷新。取消长按仍不提交预览水位。
- 本机模式继续用原 localStorage 格式和原子单次写入，Web Lock 与原始数据版本阻止旧标签页覆盖新数据。读取损坏数据仍保留原文并阻止普通写入，明确清空后才替换。
- 账号模式以快照版本在 IndexedDB 同事务比较并保存，记录/设置/杯子与待同步 mutation 一起提交。两页面基于同一旧版本同时保存，最多一方成功，另一方提示未保存并刷新视图，不能静默覆盖。
- `BroadcastChannel` 与 storage 事件通知其他标签页。迁移归属标记只用于失效通知，不是登录凭据；即使旧页面读到了新标记，也不能继续用旧会话保存。身份/命名空间切换会失效旧会话与撤销机会。
- 同账号的多个标签页还通过 Web Lock 串行执行 Worker，避免重复分页任务相互竞争 cursor；服务端仍独立验证幂等与版本，不把浏览器锁当作服务端安全条件。
- 拉取与其他页面更新会刷新当前视图；内容相同的网络确认不消耗撤销机会。异步读取通过代数标记防止旧读取覆盖新保存，失败提示不被紧随的刷新吞掉。
- 验证开关开启时，本机写入后短暂合并触发同步；联网恢复或回到前台也触发。没有定时无限心跳。状态仅在当前写入代数未变化且 Worker 确认已完成后显示“记录已同步”，其他状态明确为等待、同步中、错误或冲突。
- 冲突暂停自动同步并保留队列，可导出备份；不自动选胜者。冲突解决界面仍待产品确认。账号模式的备份替换和清空明确告知变更也会同步到云端，原单机副本不删除。

## 验收

- 57 项 Node 单元/事务测试，包括去重（含 JSON 字段顺序差异）、墓碑保护、目标选择、当前设备杯恢复、首次迁移失败整体回滚、双写者版本竞争、旧会话失效、账号隔离与跨标签页 Worker 串行化。
- `npm run test:browser` 使用真实 Chromium、320px 手机尺寸和模拟 Auth/REST：确认前无上传、取消无上传、合并及云目标、原副本保留、第二标签页切换、离线重开/记录、联网补传、主动更新保留数据；额外使认证凭据过期并断网，验证 5 秒内仍可打开账号本机快照和入队记录。默认开关关闭时也能读写已有账号快照，不发记录 RPC。
- 浏览器回归在独立临时构建中注入虚拟 publishable 配置，接管所有 Supabase 请求；不使用真实认证凭据、不写真实用户数据。CI 先运行此回归，再构建正式 Pages 产物。
- SDK 分包由离线清单完整缓存，两个 JS 包均低于构建分包提示阈值。
- 未验证：真实 Supabase Auth/REST（环境域名策略仍未放行）、真实多设备、Safari/iPhone、30 天过期与清理、账号绑定/找回和冲突解决。完成这些并检查线上构建变量后，才开放正式同步；不将预览通过当作完整 V0.2 已上线。
