## v0.3.1 网络状态与榜单浏览

- 排行榜/成就页的身份读取与 RPC 都有超时和取消。切换指标/账号或关闭弹层不会把旧请求结果写回；返回前台更新服务器结果。
- 榜单响应经有界分页、类型/次序/个人状态校验，保留公开允许字段；畸形响应进入可重试错误，不触发渲染异常。相同快照刷新保留已加载41行等完整结果；真实变化回到前20并提示。支持tab左右键/Home/End。
- 隐私未知/写入结果不确定时不会伪称已关闭，提供重新读取；离线显示上次状态且禁止提交。账号变化立即撤回旧状态。
- 新增 public.leaderboard_preference()，只读取 auth.uid 对应偏好（默认true），避免进入「我的」时计算全站榜单。私有helper验证存活账号、固定空search_path，匿名无权，公开wrapper为invoker。迁移只增加两个只读函数，不修改原数据或写入路径。
- 部署 SQL：supabase/leaderboard-preference.sql，SHA-256 e727af1113068d343ce04bfcc4e87fef3e196fdda0051283cb1df249fc6d15d4。真实迁移编号：20261016180112_add_lightweight_leaderboard_preference。
- 相关验证：单元（异常页/跨页保留/取消等待）、正式SQL三轮及轻量状态匿名拒绝/true-false、320px榜单刷新保留/键盘切换/真实SQL+成就缓存/跨账号已通过；不为此批前端变更重复执行无关生命周期和邮箱全套，本仓库CI照常执行发布门槛。
- 不新增业务门槛、不改五榜/成就口径、不删除真实数据、不启用Cron。真实设备/大规模压测不冒充完成。

## v0.3.2 记录浏览与恢复

- 在设备本地日历下选择日期：跨年显示年份、回到今天、今日禁止继续向未来空日翻页，非法日期拒绝。云端北京日口径不变。
- 当天全天饮水/嘘嘘汇总独立于筛选；筛选无匹配时可回到全部。首页“全部记录”明确取消旧类型筛选。
- 历史分组、杯内明细按50项加载，来源/总量未截断；日数据、分组和七天回顾使用memo，不在输入等每次渲染反复扫描全量记录。
- 修复只改水量时原始记录秒数/毫秒被分钟输入框抹掉的问题；未改时间则沿用原ISO时间，主动改时间仍按输入值。保存期间禁重复提交/关闭确认，整杯删除页内确认且仍可撤销。
- AppRecovery 在意外渲染错误时提供更新后重开/当前版本重开，不自动清数据。prepareRefresh 可以从已存在worker恢复更新入口，即使正常App尚未挂载。
- 本地数据可读但格式损坏时，不再指引先清空；允许从已校验有效备份进入原有显式覆盖确认流程。确认前原始字节保留，导出按钮仍禁用，避免把空兜底状态冒充有效备份。
- 相关验证：本地日期单元、America/New_York 320px 浏览器，精确时间保留、补记/日期/全天汇总、删除取消撤销、322条来源数据分批不丢失、模拟渲染故障重载原数据不变、损坏JSON确认前保留/确认后恢复。无生产Schema变更，不改业务规则。
