# 开发路线

1. 已完成：仓库初始化、技术选型、本地记录演示、统计逻辑、数据库结构、CI。
2. 下一步：微信登录、会话与权限中间件、数据库迁移执行器、记录增删查、幂等同步和日统计。
3. 排行榜：周榜聚合、参与设置、共享名次、分页，加入隐私和账号删除能力。
4. 小规模内测：真实 AppID、HTTPS API、托管数据库、备份恢复、限流、错误监控、小程序隐私说明与审核。
5. 验证用户需求后，再评估 iOS / Android；共享 domain 与 API，单独实现平台登录和存储适配。为微信账户增加安全的绑定机制。

尚需产品决定：自定义杯量、补录时间范围、是否需要好友/小组榜、是否支持自定义时区。初期先按固定杯量、本地演示及记录天数榜推进。
